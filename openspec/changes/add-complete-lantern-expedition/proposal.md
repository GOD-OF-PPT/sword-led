# Change: 从短试锋推进完整护炉主线

## Why

用户实际玩v6后再次认为无聊，并明确“没有完整的游戏主线”。独立短段没有章节、人物承诺或跨节点成长；新的产品／玩家反馈研究也提示工具演示后即结束不能承担持续旅程。

## What Changes

- 新增独立forge-v7/schema7：三章九节点、同剑与备用剑跨关、公开威胁／机关、持续工具成长、实际钱与营地、剧情选择后果、唯一灯芯与三种闭合结局。
- 简化首锤手续，普通锤直接可用，技法在实际用出时形成工艺；新规则和全部数值、分支及手算例统一在[完整合同](../../../docs/v1.0-lantern-expedition-proposal.md)。
- 一次批准覆盖完整旅程与页面，不再只实施首章／一关后重新等待章节许可。
- 本次发布范围包含新主线成为默认首页；旧v5和v6入口、SDK、存档与资源保持，不互迁钱包／剑。
- Game Studio共享架构与UI路径；保持TS/Vite、DOM/Canvas，D美术优先复用，新增有限机关／威胁前景。研究和独立设计分镜已授权，规则实施尚未开始。

## Impact

- 新能力lantern-expedition-campaign，独立core-v7／SDK／codec/session／presentation-v7。
- 不覆盖旧v6的三回合、固定尾声合同；不把新主线回写旧档。
- 不加QTE、多轴工艺、开放世界或大规模兼容矩阵；必要完整PC路线与保存边界跟随实施。

## Approval

用户已于2026-10-23具体确认“确认，完整实施至结局”。批准原答、原commit与合同SHA在`docs/approvals/v1.0-2026-10-23/approval.json`；全部范围直接实施，不再重复确认D风格或左键。实际阶段与发布/最终复核见本变更tasks.md及`docs/iterations/2026-10-23-lantern-expedition/tasks.md`。
