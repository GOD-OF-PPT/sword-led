# Change: 打造有打法的剑并亲自试锋开路

## Why

用户明确否定当前趣味与视觉吸引力。v5单一strike／阈值交付、有限钱袋与被动成长使“点击了什么”与“亲手造出的剑有什么新用途”连接薄弱。新的Steam评论研究也提示创作、超规格奖励、重复劳作与成品后果之间的张力，不能用已有技术检查／内容数量代替改造。

## What Changes

- **BREAKING，仅独立新模式**：拟`forge-v6`／schema6，强度、完好／裂纹、每柄6记上限、每炉1次下一记主动技法。
- 两条实际不同的打法：稳锋保完好并探隙，裂炉主动造裂／破甲、命中后磨损。仍左键，不重启十点／逐锤工具／时机／热应力多轴。
- 三回合木盾卫机，用当前剑正式算伤害；过门一次15铜钱。安全基础剑能过门但不够拿匣：吊索完好强度≥5、铁闩实际伤害≥7；取匣阶段只直接尝试目标／离开、无架剑／探隙，争匣至少多承担一记普通风险。最多取一工具，固定尾声实际使用回锋追斩或破甲回充。
- 只交约90秒的单段主门＋工具第一次使用，不先做十二章、大敌群／无尽遗物，也不把短段叫完整v0.9长篇游戏。
- v5完整十二天、计价、SDK、存档／炉谱及旧入口保留，首段不迁旧资源，不自动切默认首页。
- 完整数值、失败调整、手算例、视觉因果及确认对象见[正式方案](../../../docs/v0.9-sword-expedition-proposal.md)。所有算例未SDK运行，未实施。
- 尾声锻造可在剩余三坯内调整且不返充能；尾声试锋只有一次3回合，失败即带主门成果进回顾，不重置再试。崩炉主靶成功后只允许一次回炉用回充，不再开试锋或补供给。

## Impact

- Affected specs：新增`sword-expedition`。当前无已归档能力，新能力以ADDED定义，不MODIFIED覆盖v5／旧提案。
- 批准后拟新增core-v6、正式SDK、schema6 codec/session、独立v6页面和表现适配；不在旧renderer回调计价／发工具。
- 不迁引擎、不新增远程服务／依赖／移动或低版范围；必要检查与单PC体验跟随实际变化，不起旧384／1000种子／全音频原生矩阵。

## Approval

**待确认，未实施。** 用户原始要求“然后确认实施文档”，OpenSpec祖先AGENTS要求“Do not start implementation until proposal is approved”。本次新增动作／风险／胜负、酬劳／奖励与独立存档合同，需要确认完整具体方案；旧v0.8批准不覆盖这些新规则。

普通现版UI／因果视觉修补仍沿已有授权，不因此额外暂停或要求重复D／左键批准。提案／严格校验通过只说明文档可审，不代表同意实施或新玩法有趣。收到具体批准前，不创建v6生产核、SDK、codec或新玩法接线。
