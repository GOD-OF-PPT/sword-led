# 3i.6：让收工与旧刃交换的后果提前可见

2026-10-21。本页是已批准v0.7规则的引导修复，不增加规则、货币、数值或页面。已在正式30,000生产、独立30,000审计及模型归档真实终态后实施，并通过三引擎、两PC尺寸的42项定向消费者；[实际结果与边界](reviews/T11-4-2-3i6-v4-balance.md)记录完整红绿及官方预览。冻结批次期间未修改代码。

## 已确认的缺口

现app收工只说明当日是否达标、回收/留剑和剩余契印，开场也没有公布三关键日及至少十项要求。只有终局才说明关键约定；修回契印并不能修复已经失约的关键约定，玩家事前不能据此选择。

旧刃回收事件没有挂剑时只说“可以拒绝”。实际可将当日廉价余剑挂入现有剑架，再回同一事件交换；名称和提示容易使玩家误以为只收真正昨日旧剑。弹窗已有价目和确认，不需要新交易机制。

## 既有页面内的修复

1. 开场与主动打开的灯路回顾各保留一句完整目标：“守住第4、8、12天的关键约定，至少完成10项，并带着契印归来，才能让十二灯复明。” 跳过开场的玩家仍可回看，不新增常驻十二格面板。
2. 当天属于关键灯站时，纸单给出短标记。收工确认从正式settlement公开投影读取：关键未成会保留不能用其他单替代的缺口；护炉契只保印、不补关键约定；契印归零明确本局在此停下，不统一写“仍可继续”；普通失约且尚存契印才说明可以下一程。关键达成不提前宣布全局胜利。
3. 旧刃事件没有挂剑但有可用余剑时，解释可先挂架并提供“回铁砧选剑挂上”导航；关闭弹窗后聚焦现有选择/挂剑控件，事件仍未答应也未拒绝，不自动挂剑或发钱。没有余剑时如实说明，拒绝始终可用。
4. 交换确认并列所选剑的实际身价和现有核心事件结果（160金币），指出交出后不再兼作交付/留剑；次日有旧剑路线时沿既有明日纸单提醒。沿原确认票据与V4Session命令发送，导航和取消均不得改变进度。
