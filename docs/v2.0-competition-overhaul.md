# 《锤下求生 · 护炉远行》典藏大成版架构说明

## 一、美术与舞台重塑（回归并升华手绘宣纸青铜国风）
1. **纯正楷书宣纸与松烟暗夜视觉母语**：全面采用楷体书法排印（`Kaiti SC / STKaiti / KaiTi`）、宣纸泥金卷轴（`#ead7b2`）、深松冷夜底色（`#091923`）与铁木炉火暖铜（`#f1c486 → #bd783d`），全界面零 Emoji 符号、零生硬几何色块，以手绘烛芯水滴、菱印与水墨画卷统一视觉层级。
2. **全屏无遮挡山路与实体飞剑/锻锤物理演出**：
   - 完整保留 `100dvh` 手绘远行山路长卷（炉车与山道浑然一体），将 HUD 收敛于四角地平线，绝不遮挡道路中央视觉焦点。
   - **840px 四阶手绘横剑（`sword-stages-v1.webp`）**：通过离屏 `source-atop` 熔金火纹着色、定线金脉与崩纹裂痕实时渲染四阶剑身（粗铁坯 → 开刃剑身 → 淬火成剑 → 传世名剑），并在出剑、双剑合璧、留剑撑危梁与嵌剑复明时呈现完整抛物飞剑斩击、插地定格与七道母灯金光复明演出。
   - **690px 实体铁匠锻锤（`hammer-forge-v2.webp`）**：锻锤随鼠标与 `[A / S / D]` 沿剑尖、剑脊、剑格三部位平滑游走，落锤瞬间呈现蓄力抬锤、破空砸落、火星飞溅与镜头微震反馈。

## 二、主线叙事与严格单焦点「引路」指引
1. **九站重燃母灯顶栏路引**：左上角常驻九站长灯进度条（`①巡夜 → ②断桥 → ③险渡 → ④营地 → ⑤双驿 → ⑥避难 → ⑦风脊 → ⑧灯塔 → ⑨母灯`），玩家随时明确当前所处山程与登顶目标。
2. **战前「前路探报」**：每站推车出发前直观展示前方拦路敌影立绘、血量护甲与手中兵刃预计一剑伤害，先知先觉再抉择是否开炉铸剑或切换剑势。
3. **同行伙伴口语「引路」与严格单焦点火印**：杜伯、阿禾、阿岚以半身立绘与一句平实口语提示眼下最关键的一步，且全屏幕同一时刻**仅有唯一推荐按钮或目标**点亮暖金火印（`引路`），彻底消除多按钮同时闪烁的视觉干扰。

## 三、铸剑与护炉战术可玩性闭环
1. **四阶横剑三部神锻**：任选「寒星长剑 / 断岳重刀 / 镇岳阔刃」，在 `[A] 剑格·守心`、`[S] 剑脊·断岳`、`[D] 剑尖·穿云` 三部位间看准金火甜区落锤（前 3 锤安全定型、后 3 锤高温冲星）；任一部位累计落满 2 锤即领悟专属**零行动剑技**（《回风守心》《断岳重劈》《流光穿云》），再择**寒泉水淬 / 赤脂油淬 / 暖灰炉封**收剑入鞘，收录入 12 柄《铸剑百炼录》。
2. **乘胜追击连斩与双剑战术**：每轮基础 2 点行动（`◆ ◆`），本轮**首次击破或打断敌方蓄势立即触发【乘胜追击】返还 +1 行动与 +1 剑意**，配合零行动剑技、三式剑势（正势 / 破军 / 止水）、零耗换剑、伙伴援手、双剑合璧与空格迎锋卸力，打出酣畅淋漓的一回合连斩破阵；辅以 9 件护炉遗珍 × 6 组炉火共鸣与五卷直达试炼残卷，直通「万家薪火 · 剑魄归宗」真结局。
