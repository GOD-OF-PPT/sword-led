# v0.8 第一章：三柄行囊

默认入口 `/` 现为 v0.8 首章四天；左上显示“v0.8 第一章 · 三柄行囊”。原十二天行程从标题页的“旧版十二灯行程”或 `/v4.html` 继续，旧细锻/契约入口仍在。新旧行程分别保存，不会将旧金币和兵器搬进新经营。

左键点剑身落锤，合格后可从剑架拖给来客，也可用右侧交剑按钮。剑旁是**作品身价**，交剑按钮是**实际收款**；委托酬劳和品质奖金在纸单/收件回执中分开列出。多锻得到的高身价不会全额变成金币。

行会每天的钱袋有限，品质奖金、出售和回收共用。钱袋空时普通出售禁用，剑仍在；合格委托的基础酬劳仍照常支付。主动回收和收工前会列出真正入袋的钱，零回收也会交出兵器，先看清再确认。

明日总共三柄：不留剑就领三新坯；留一柄旧剑便只有两新坯，取下旧剑不会补第四柄。“明日打算”和收工确认都展示下一单与留剑是否合用，可返回调整。第四天选余温架后，跨天留剑可增值15%，原裂纹/锤势保留。

第三天商人到访。等级至少3的成器才能换手艺；成功加1级、大成加2级，不必固定敲三次。铜钱可买下一批更好的来料或补契印，页面显示当前现金、花费及未来底价；当前剑不会因备料购买而涨价。

炉谱标记每件作品来自旧行程还是新经营。导入旧主册/备份时先查看具体来源和作品，再明确确认；来源变化会要求重新预览。导入只合并解锁/最佳作品，当前局资格不变，下一次启程才使用已保存的新资格。

第一章完成后保存第四天、所选炉具和作品，停在首章收束；第二章页面开放后可在此续接，不把首章称为十二灯结局。新纯核已经保留十二单和三结局，中后段页面为下一阶段。保存失败、只读或不保存模式仍可在行囊/保存详情中导出与处理。

本轮实际首章记录：4/4委托、3契印、374铜钱、余温架和一柄留剑；这是固定种子的可达性与交互记录，不是对所有种子或趣味性的承诺。[实施与复核](reviews/T11-4-2-3l3-first-chapter.md)保留范围与红绿边界。
