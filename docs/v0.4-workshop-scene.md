# v0.4 行旅版：让操作回到工坊

本轮针对用户“界面像软件工作台、提示和动效不足、推进整体完整性”的方向，改造运行中的工坊与整局表现。继续使用D「行脚灯炉」、简单左键和既有十二轮规则；[完整规则](v0.4-gameplay-proposal.md)与[契约流程](v0.4-campaign.md)保持各自版本身份。

## 场景与操作

移除包住剑架、铁砧和订单的三块完整矩形面板，背景工坊直接成为舞台。当前剑、锤头与身价居中；左侧是三柄配给和保险剑，右侧是悬挂契纸与随身手艺。布木底牌承托顶部契约进度和底部主要动作，印记以三枚契印呈现，十二轮路标标明达标/失约和商人轮次。

保留身价、差额、裂损风险、六格锤势与三个主要动作。鼠标左键点剑身直接落锤；空格松开和Enter仍可使用。正常保存缩成炉边状态，恢复/读档/不保存出口在出现故障时展开；设置和可选“玩法图解”放在边角，不增加必经操作。

炉边提示根据真实选剑和状态变化：第一锤怎么敲、身价需要交差才入账、这一柄是否足够补差额、裂纹的下一次后果、安全连锻、已达标后的留剑/商人选择，以及空台如何继续。提示不修改概率、不自动出招、不替玩家选最优路线。

## 动作要看见结果

| 实际事件 | 表现 |
| --- | --- |
| 普通/大成/裂损/断剑 | 沿用已校正锤面、火星/碎片、局部冲击、身价浮字与分结果音色 |
| 交差 | 实际成品剑影飞向契纸，金币区域响应，交差金额与目标立即按正式结果更新 |
| 首次跨过本轮目标 | “委托达成”短幕与契纸响应，仅在这次Accepted交差出现 |
| 挂剑/取回 | 剑影归架或取回提示，明确裂纹、锤势和风险不重置 |
| 换手艺/领赠 | 交易剑交接，真实手艺名称、作用和入袋提示 |
| 升级/补印 | 显示正式更新后的未来底价或印记数量 |
| 新一轮 | 新配给/目标短幕；第3、6、9轮提示商人到场 |

收益由核心先原子结算并保存，动效只解释结果。立刻继续操作、暂停、菜单、失焦、隐藏或新局都会清掉旧表现，不会等动画结束才发钱。刷新/继续读档不补播达标或奖励。减弱动效使用短暂静态文字，停止飞剑/光圈；静音仍使用原设置。

## 一局有开头，也有收尾

契约菜单保留当前进度、继续、新建与模式选择；种子是显式选项，新建仍要确认覆盖。主动打开的三步图解解释锻造、收手和经营。商人界面用原有人物和实体手艺道具组织摊位，交易、升级、修补和取消的实际后果仍清楚。

每轮收据展示真正参与本轮的兵器、身价与交差/回收/断剑/换手艺/保留去向。终局以实际最高身价的兵器呈现本局作品，保留真实达标轮数、金币、峰值与完整账本；断剑不会被画成完好奖杯。三轮练手仍有独立结束页，失败与十二轮完成分别说明。原两版入口和原存档保留。

## 实现与素材

`scene.ts`只读核心生成提示、旅程和兵器故事；`scene-feedback.ts`只处理新Accepted事件，最多8个临时表现节点，拥有并清理全部动画/定时器。主装配继续从同一持久化会话发命令。剑架、保险剑和赠品按run/generation与实际显示状态保留节点，仅尺寸/画稿变化时重绘，避免缩放把键盘焦点丢到页面。

两张新素材由内置imagegen生成：悬挂契纸与靛蓝木作底牌，运行共574,496字节。原PNG、完整提示词、直接风格引用和hash在[素材清单](../design/d/scene-ui-manifest-v1.json)；WebP导出alpha与原图逐像素一致。没有把整张概念图覆盖在交互上，文字、数值、按钮、兵器和特效仍由代码和实际状态驱动。

本轮的实机、修复、报告身份和验证结果见[R3.15](reviews/R3-15-workshop-scene.md)。[新规则1000种子模型审计](reviews/R4-v3-model-audit.md)已完成，并暴露稳定配方/弱经营取舍。整体趣味性仍需优化与真人复验，最终更广矩阵与最大R4保留在目标任务中，不能用这轮美术或技术结果代替。
