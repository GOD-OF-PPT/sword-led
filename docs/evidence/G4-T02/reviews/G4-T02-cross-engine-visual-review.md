## 触点与证据边界

截图中主要按钮具有独立边框及清楚的操作文案，未看到被别的画面层遮住的核心操作；F1280/F1920 的保存操作按钮排列紧密，是本组选图中最需要实际命中区域证据的区域。这里只判断可见外观；未通过静态图片推断 44 CSS 像素命中范围，也未重新验证鼠标、触屏、键盘、焦点陷阱、滚动可达性或按钮真实启停状态。

原 PNG 分辨率为 2560×1440 / 3840×2160；本次图像工具将全部 6 图呈现为 2048×1152，因此对微小字号的原生像素细节、字形边缘或精确对比度不作结论。Firefox 同目录的 `changed-backup-requires-review-run-geometry.json` 提供了两种 CSS 视口、DPR 2 与面板文字，未提供命中区域尺寸。

三个引擎各选了不同场景，此复核覆盖的是指定画面的版式与可读性，不构成同状态的跨引擎像素一致性结论。未启动浏览器、未重跑矩阵、未修改 `src` / `tests` / `dist`；主/尾矩阵终态由主控独立核验。未评估 H 乐趣，不作系统 Safari、真实移动设备、动画/性能或全部游戏流程的结论。
