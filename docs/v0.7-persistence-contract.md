## 所有权与版本

局档使用`sword-led.save.v4`/`sword-led.save.backup.v4`，schemaVersion4、rulesVersion forge-v4，全部快照由正式validateRun重建。复用既有256KiB限制、保存时间、有效旧主档备份、CAS、dirty/恢复与generation/epoch。旧v1/v2/v3解释器、key与共用`sword-led.writer`锁不改，不迁移旧journal。

炉谱另用`sword-led.collection.v1`/`sword-led.collection.backup.v1`，schemaVersion1、独立规则标识。只存章节集合、配方熟练集合、六手艺见闻、挑战资格和最多12份作品收据，不存金币/消耗货币/随机/可重复领取。配方自由开局资格从章节派生，light始终可用；第一/二章给guard/heavy，真正victory给challenge，当前局创建时冻结资格。

作品收据包含commissionId、实际day/routeId、runId与一/两柄真实交付剑；数量/路线/兵器结构必须合法。每个委托最多一份：总身价更高优先，同价用稳定规范序列择优；集合合并满足交换/结合/幂等，不因导入顺序改已有最佳记录。熟练来自真实合格level≥9作品；永久集合不是反作弊服务，但不能接受结构无界、错误ID/去向/数量或不满足所记路线的作品。

## 同步、错误与恢复

仅active、writer、仍持同源租约、无局冲突且局已成功保存时，将该合法局getCollectionAwards并入最新有效炉谱。Accepted局写失败先保留内存状态，retrySave成功后才同步永久成长。memory不保存炉谱。读取/回顾/恢复集合不发经济命令，不重抽随机或重复发奖。

局保存与炉谱保存不是事务：分别提供状态/错误。炉谱失败保留已保存局和待写集合，重试先读最新磁盘再做并集，不能覆盖别的已取得作品。重新加载合法局可重新派生缺失集合。新建前再次同步；若实际取得的集合仍未安全落盘，返回collection_pending，避免覆盖唯一可恢复来源。玩家仍能继续当前局、导出局与炉谱、重试。没有静默放弃成长的默认路径。

Accepted但局尚未保存的新成果只参加pending保护，不提前加入永久data；应先retrySave再重试炉谱。lastSave记录最近一次写尝试，当前问题以problem/pending为准；并非看到旧lastSave失败就判定现档仍未保存。

未来版本、坏档或不可读炉谱不自动清空/覆盖。空主档但备份非空（包括不可读或未来版本）也先保留恢复入口；恢复要求当前generation和confirmed=true、合法备份，重新检查主/备后写入并合并当前已保存合法局。若主档已经有效，拒绝用旧备份覆盖它。普通主线可在无可验证炉谱资格时以light开始，挑战仍锁定；旧原文可导出，无法恢复时仍有明确不保存试玩。显式恢复坏/未来主档意味着选择用本版合法备份替换，不能说成自动迁移。

跨窗profile事件刷新只读集合，不触发局save_conflict；同源租约阻止两个游戏版本同时写，CAS再防非合作外部改档。暂停/pagehide释放锁、pageshow真实恢复重新读取；旧输入/旧异步激活不能提交。销毁移除全部事件/订阅，不允许迟到profile写入。集合单独订阅，普通界面订阅不能撤销Accepted经济结果。

## 接口与验证

v4 SDK公开独立codec/repository、createV4Session（注入存储/租约便于消费者）、createV4BrowserSession，以及集合读数/订阅/重试/导出/备份恢复接口。新局应用输入只含runId/seed/mode，资格由当前合法炉谱决定；直接纯核createRun保留显式资格以支持正式回放。

| 接口 | 使用约定 |
| --- | --- |
| getSnapshot / subscribe | 原有局身份、状态、dirty/conflict与保存结果；返回规则不变 |
| getCollectionSnapshot / subscribeCollection | data、load、pending、problem、lastSave和当前writable；两种保存状态独立 |
| retryCollection(generation) | 重新读取、并集、尝试落盘；不重发交付/收工命令 |
| recoverCollectionBackup({generation,confirmed}) | 明确恢复合法备份；主档有效时拒绝 |
| exportRun() | 当前完整局快照JSON，包含冻结资格与journal，可由validateRun复核；未开局为null |
| exportCollection() | 已知集合与主备原文读取结果的JSON包，保留未来版本原文；导出不清pending、不写档 |

共享会话只增加可选isTerminal适配口，默认仍victory/defeat，v4额外识别return。外层先同步安全集合再发布通知；通知期间拒绝经济/新局重入，暂停/销毁补发最新身份，销毁撤销全部订阅和窗口监听。

作品收据的磁盘校验只证明结构/领域条件；它不包含完整journal，不能声称每份收据本身已完整重放。实际写入来源是内核创建或正式回放接受的局，collectionFromRun对外会先正式回放未知输入。

验证覆盖真正chapter/三结局/witness恢复、两档组合写失败和读失败、当前/未来版本、空主有备、资格不可偷传、集合幂等/择优、旧key原字节、多窗/缺锁/memory、陈旧generation/生命周期与无副作用导出。浏览器测试使用隔离profile和正式SDK，不修改用户存档，不赋值钱包/终局。当前生产网页接线、作品页/新场景和真人体验不由本任务消费者替代。
