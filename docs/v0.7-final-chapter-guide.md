# 山口终章：第9–12天与炉谱

本页说明已批准v0.7的终章操作；本任务技术验证结果另列交付报告。沿原行程继续，不会重置配方、炉具、手艺、留剑或随机状态。第8天装好第二件炉具后，点“沿灯路，去下一天”进入第三章。

## 最后一程怎么做

- **炉火回响**：一柄身价至少1000、完成至少两次安全连锻的剑。剑旁会显示实际等级和已完成连锻次数；锤势六格满后，再落锤才会触发一次安全连锻。
- **缺口之剑**：护刃有两条路。带裂身价至少1150，或无裂身价至少1800。先看风险，再决定收手；同一柄不能既交出又留下。
- **最后的接力**：此前留下的旧剑至少1300，一柄即可；也可以做两柄当日新剑，各至少850。交第一柄新剑只记1/2，仍可改用一柄合格旧剑接完。已经交出的新剑不会被退回，也不会冒算为两柄。
- **山口护灯**：无裂重锋，等级至少9且身价至少2500。价格够高也要检查等级与裂纹。交剑后会验看实际作品；安排余剑并收工，才会决定整局结局。

第三位商人在实际第9天到访，升级只影响后续新坯；当前剑保持原值。第9/11天的炉边事件仍可接受或拒绝，代价与结果在确认前公开。挑战模式会重排章内委托，以上条件随委托走，商人日期保持第3、6、9天。

第一章来信已有通知与回顾入口：真实推进到第3天时，会出现“阿禾捎来的第一封信”，可点“展开灯路回顾”；第3天以后也能主动打开灯路回顾重读。第7、11天分别有雪中来信与山口来信。回顾不推进日期、不发奖，读档不会补播这些推进通知。

## 这一局留下什么

“十二灯复明”需要第4、8、12天关键委托都成、总共至少10项完成且仍有契印；因此胜利页会如实显示10/12、11/12或12/12，而不会抹掉失约。“灯下归途”保留已经做成的护灯剑，同时列出缺少的关键约定或完成数量。契印用尽则“炉火暂熄”，尚未抵达的地方不写成失败或虚构救援。

结局点“听听三人的后话”，可直接展开阅读区，再选择阿岚、阿禾、杜伯，查看各自委托完成、留下遗憾或尚未抵达的记录，以及交出的作品。重看和刷新不会重复计奖。

炉谱保留十二项委托的最佳真实作品。点“翻看这件作品”可看路线、实际交付日、来料日、配方、等级、普通锤数、安全连锻次数、裂纹和身价；挑战的实际交付日可能与委托编号不同。未收集的页明确留白，不生成假作品。

章节解锁护刃/重锋自由使用，合格等级≥9作品留下配方熟练，学过的六门手艺留下见闻。永久成果不会给新局叠金币或倍率。成功结局安全写入炉谱后，标题和炉谱会提供“行脚挑战”；另开仍需明确替换当前行程。炉谱待保存、不可读取或当前页只读时，先处理保存状态。普通主线始终可以重新开始。

选择“不保存试玩”（memory）时，当前局不写盘，章末和结局也不会把本次新作品、章节、配方熟练、手艺见闻或挑战资格写入炉谱；离开前可导出这次行程。旧炉谱中已经安全保存、合法可读且无待处理保存问题的挑战资格，仍可用于开启临时挑战；临时挑战及其新成长同样不写盘。本次临时通关不会新增持久挑战资格，旧炉谱记录保持原样。

本局和炉谱分别保存。出现警告时可点“保存详情”重试本局、重试炉谱或导出；不要用新局覆盖尚未妥善保存的成长。旧版契约仍在独立入口，旧档不迁移。本机试玩不是公网部署；最终规模、广DPR/原生音频性能和真人体验验收仍是后续独立工作。
