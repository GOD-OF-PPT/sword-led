# 第一章 · 灯从炉起

标题点“启程”后点火。鼠标左键直接点剑身落锤；也可用 Tab 选择、空格落锤，不需要卡时机。看剑旁的身价、裂纹和下一锤风险，够用时交给右侧来客。

| 天数 | 来客要的剑 | 当天的新取舍 |
| --- | --- | --- |
| 1 | 无裂纹，身价≥100 | 先保住第一站，再决定余剑去向；首次完成后可领一门手艺 |
| 2 | 无裂轻刃，身价≥160，普通锤≤4 | 锻得够好，也要够轻快；能保留一柄给明天 |
| 3 | 身价≥260，经历过安全连锻 | 六格锤势后再落锤触发连锻；商人可用剑换手艺，当日还有一个种子事件 |
| 4 | 无裂护刃，身价≥360 | 自动推荐借来的护刃配方；守住渡口后，选择下一程的炉具 |

首锤前可换已可用配方；首锤后定型。“交给来客”才完成主委托；“卖给行会”只换金币。回收只得底价四分之一，留剑不会被收工回收。收工前会明确剩余去向与契印后果。

裂剑仍能加工或出售，再裂会断；下一锤风险公开，刷新不会重抽。断剑会自动回收并切换下一柄。赠礼和商人手艺各有真实作用；本锤实际生效的挂件会亮起，可点它看说明。商人备料只提高未来来料，眼前的剑不会凭空涨价。

事件可以接受、拒绝或暂不决定；接受前会说明钱和剑的代价，收工/失败收据记录真实后果。完成委托后会出现可跳过的用途短场景，读档不会重复发奖励。渡口亮/暗和留下的遗憾由实际结果决定。

第4天改造后完成第一章，可点“沿灯路，去下一天”进入[第二章](v0.7-second-chapter-guide.md)；旧第一章完成档也可明确继续。当前页面开放到第8天改造后，不等同十二灯全局通关。合法保存后，炉谱记录作品与第一章资格，新旅程可自由使用护刃，金币不跨局继承。

右上“存档”可重试、导出、查看合法备份或明确不保存试玩。另一窗口占用时只读；关闭占用页后可明确重新读取。局档、炉谱与声音设置各自报告保存结果。新版本不转换旧契约，标题“行旅种子与旧路”可续玩 `/v3.html`，旧D细锻 `/v2.html`、B版 `/legacy.html` 也保留。
