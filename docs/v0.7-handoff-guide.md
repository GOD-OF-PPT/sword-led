# 炉前交接

刷新原试玩地址 http://127.0.0.1:4179/，标题和炉前左上显示“来客纸单”。已有v4旅程可继续，不需要重开。

## 在炉前做决定

鼠标左键点中央剑身落锤。铁砧上方只讲这柄剑眼前的事：还差多少身价、是否缺连锻、配方或裂纹条件、现在能否交给来客。底部六格火星是锤势，蓄满后下一锤安全连锻；普通锤仍有页面明示的风险。可以随时收手，不必为攒火星一直冒险。

左侧候火剑单击选中；按住一柄拖向右侧来客，或拖到“留一把，待明日”的剑架。目标会亮起，拖动中的提示说明这柄能否交付。松手才交接，Esc可收回。拖给来客的剑必须合纸单；不合格会说明差项，不会代卖。想换旅费，使用明确的“卖给行会”按钮。原交剑、留剑与键盘操作也保留。

来客收剑后，人物伸手、纸单盖印，并在原地留一张收件回执。可以继续安排余剑，或点“收炉，准备启程”；不用每次离开工坊再翻回来。“看看灯路”可主动展开用途场景；第一单回执可以直接领取首赠手艺。章节、日终与结局仍有完整场景。

## 留、换与启程

“明日打算”展示真实明日委托、新坯底价与旧／新剑替代路线。已经挂架的剑会显示明日真实预览价，以及是否已合一柄要求；两柄单不会把一柄算两遍。可以在这里选择余剑挂架。换下已有留剑会再次确认，旧剑回到炉边；两柄不会同时跨天。

商人摊位说明每门手艺对当前／明日计划的用途，交换按钮显示当前剑价。交出的剑不能再交差、卖钱或留给明日；满三槽时还需选择换下哪门，最终确认仍重述献剑代价。备料显示实际报价、付款后的余钱与明日普通新坯底价变化，手上已有剑不涨价。

本轮优化沿用D“行脚灯炉”、自然锻锤和现有兵器成长。规则、随机流、计价和存档版本保持；没有用新文案声称解决先前发现的后期金币富余问题。玩法数值的后续优化需要明确的新规则设计。

实现边界与公开投影见[炉前决策说明](v0.7-forge-decisions.md)，本轮实际画面、试玩和修复记录见[R3.21](reviews/R3-21-forge-handoff.md)。

## 成器与实物交接

锤头每次真正接触剑身时，造型、剑价和本记手艺反馈一起更新；连锻不再先跳到最终总价。真正跨过初开锋、叠纹、流火、名器的等级时，剑上有短扫光和实际阶名；裂损与断裂优先，不误播成器庆祝。减弱动效用静态阶名，下一次操作清理。

交剑、挂架和换艺使用实际作品快照作短交接，拖放从松手处接续。来客按当日已收的真实作品持剑，部分交付也保留第一柄；暂停或弹窗取消演出仍保留已经接受的结果，刷新恢复持剑而不补播动画。自然锤比例与原游戏数值保持。

新的金币、留剑三槽和成器换艺规则只在[v0.8提案](v0.8-workshop-economy-proposal.md)中，尚未实施，当前游戏仍为forge-v4。

## 路线与收讫剑位

纸单画出这一单的实际剑位，只有来客确实收下的剑才出现缩略图和“收讫”。可交但还在砧上的剑只点亮路线，不提前算完成。风雪双驿有两枚独立剑位；最后的接力把“此前留剑一柄”与“本日新剑两柄”分开，并写明任选一条。切换当前剑时，每条路线会更新真实差项。

“交给来客”的达标消息现在直接交出该消息绑定的合格兵器；它不能自动改成卖掉另一柄。裂纹消息则打开这柄的纸单差项，合格时可以在纸单明确交剑。连锻用完后满势消息失效，断剑演出期间先等真实结果落定，再继续锻造。

v0.8经营方案现已获得明确批准，原答和获批全文已冻结；新内核/保存/首章尚待后续阶段实施，当前试玩仍使用v4规则。
