## 开始与续玩

新空档访问`/`直接开启十二轮。原有三轮档继续原局，刷新不会改变它的长度或随机状态。体验完整局可点“契约”→“契约长度：十二轮契约”→“开一炉新契约”；确认后才替换当前v0.4进度，可以先导出，取消保持旧档。三轮结束页也有“开始十二轮契约”入口，仍会经过菜单与确认。

菜单也保留三轮练手。公开`/?mode=3`仅给新局选择三轮默认值，不能修改已有局。旧D细锻在`/v2.html`、B版在`/legacy.html`，各自存档与原解释器保留。所有入口共用原单写锁，另一窗口占用时按只读提示操作。

## 一局的流程

每轮三柄新剑，可以交差、回收、留一柄或换手艺；留剑保留身价、裂纹、风险和锤势。收工前显示目标差额、印记后果与剩余剑回收金额，确认后才结算。没有欠款复利或减少下轮供给。

| 时点 | 内容 |
| --- | --- |
| 首次达标 | 可自愿领取一门免费手艺，不强制打断锻造 |
| 第3、6、9轮 | 商人在新配给到手时到场，用当前未挂起的剑换手艺；满三门时明确换下哪门，也可取消 |
| 炉具升级 | 三次报价180、900、4500金币；未来底价由40逐级到80、160、320，当前剑不改变 |
| 修补印记 | 有损失且金币足够时，每次商人最多补一枚，至多三枚 |
| 第12轮收工 | 有印记即完成契约期；三枚耗尽则失败优先，不再发第13轮配给 |

三轮练手在第三轮存活时进入独立体验终点，不能计作十二轮胜利；第三轮升级仍会明确告知这局不再发下一轮配给。

## 看懂手艺与成品

随身道具显示当前选剑的真实状态：稳手保护首次裂损、余烬连锻多一锤、回响显示普通成功计次、断锋标明裂剑是否生效、继承显示已积累的下轮加值、护炉契显示本局是否用过。点道具可看完整说明，不付费、不计奖、不重抽。真实触发继续使用既有局部道具光效。

每轮收据可展开只读账本，查看目标、交差、印记、回收和挂剑。终局显示达标轮数、累计交差、剩余金币、最高身价，以及收官留剑；可展开十二轮记录和36柄真实兵器的交差/回收/断剑/换手艺/保留去向。收官留剑是本局结果，不承诺不存在的下一轮或跨新局继承。
