# 炉路交互修订：从断链调查到实际改动

用户再次评价“玩法不完整，交互动效有缺陷”，本轮没有用旧通关记录否定体验。先按Game Studio的UI、实玩与模拟/表现分离指南，独立检索ForgeTax、Jacksmith、Into the Breach、Backpack Hero的官方玩法及少量原评，再在当前默认页实际复现。原始来源/取样限制见[研究](../research/2026-10-24-v1-interaction-guidance.md)，逐项问题见[调查](2026-10-24-v1-interaction-investigation.md)。没有亲玩竞品或计算全体玩家偏好。

## 实际改变

| 玩家要做的事 | 之前的断点 | 本轮实施 |
| --- | --- | --- |
| 为下一程造剑 | 只有抽象强度，看不到用途；磨损藏悬停文字 | 正式view复用同一场次/伤害函数提供护甲、耐久、直斩与架剑后伤害；切索/撑梁/母灯用剑条件提前可读，技法就地说明穿甲与磨损。 |
| 左键锻造/成器/换手 | 人物遮锤柄，坯/剑瞬换 | 锻造收起立绘，锤点热痕与强度浮字；开坯、收锻、双剑互换、弃置分别有真实路径与去向，六记到限明确请收锻。 |
| 斩开威胁 | 目标先掉血，AP/剑强度/钱仍旧；信息藏在悬停 | 接触帧同步权威HUD，破甲/护甲抵消/零伤/磨损在对应对象附近显示，下一轮压力提前公开。 |
| 护住炉车 | 只有风线与数字，没有敌方出手 | 活敌或落石实际预备→冲击→回位，护势实际抵消、阿岚/接应/炉环减免与净灯损分别表现；结算时明确标敌方行动。 |
| 选择开路法 | 只挑一个preferred，免费援手或另一柄撑梁剑藏在talk | 所有当前机制并列显示，AP/实物代价和禁用原因就地可见；母灯还缺哪些步骤明确显示。 |
| 看懂特殊动作 | 切索等会被通用回执误称“灯芯已放妥” | 三类切索、摆渡、接应、放芯、扶座分别准确回执；工具取得/升级和救援后果在后关实际生效时说明。 |
| 前往下一站/收束旅程 | 遮罩退完才硬换背景；结局后果未呈现 | 根级遮罩最深时切地点/人物/阶段；成器不被整屏遮罩吞掉。三个结局回看实际世界后果。 |

概率、两行动、计价、供给、主线和schema7保持原合同；新增的briefing/forecast是只读视图。旧v7旅程可继续，v5/v6仍有独立入口。没有用第十站、经验条或重复剧情替代上述实际操作接线。

## 最后动效修缮与发布
