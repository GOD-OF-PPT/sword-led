## 已运行的验证

- `npm run test:art`实际构建并验证；后续在最终页面/工具版本上执行`node scripts/art/verify.mjs --out docs/evidence/T07`归档[浏览器报告](../evidence/T07/browser-art.json)。使用Node22.12.0、darwin/x64、Chrome156.0.8078.4。
- 浏览器实际解码dist中的9张WebP，与生成PNG逐像素比较alpha，差异均0；尺寸相同，8张前景确有alpha=0空隙；不以黑底/棋盘格图片冒充透明。RGB平均绝对误差2.76–3.76/255，源图和压缩图实际视检。
- 三材料×八阶×三锤×准备/接触/回弹/复位四姿态，共288组合可见铁锤边界不越出1600×900设计场景；24帧材料、八个铁件状态和九个反馈符号实际渲染。
- 1280×720、1920×1080两种浏览器尺寸无横向溢出；[1280拼装](../evidence/T07/assembly-1280.png)、[1920拼装](../evidence/T07/assembly-1920.png)、[高热临界接触](../evidence/T07/critical-hot-impact.png)、[材料矩阵](../evidence/T07/material-matrix.png)、[状态层](../evidence/T07/state-layers.png)、[反馈组件](../evidence/T07/feedback-components.png)、[商人透明叠放](../evidence/T07/merchant-alpha.png)均为浏览器实际截图。
- 已检查实际渲染文字的前景/背景对比度，所有覆盖项≥4.5，包括表单、按钮、计时条和商品状态；选择器、按钮、滑条和复选标签命中区域均≥40px。减弱动效演示与切换材料重置完整度上限通过。无页面错误/404；截图、预览源码及工具hash保留在报告中。
- 启动真实Vite开发服务，浏览器访问设计页200、24材料帧/9反馈符号、一次落锤演示、无页面错误，见[Vite报告](../evidence/T07/vite-preview.json)；验证后已停止该服务。
- 本轮`npm test`：9文件/150测试通过；类型检查/SDK生产构建通过。没有改变正式玩法核心、交易、存储或forge-v1；图片与设计页不改变规则概率或奖励。
