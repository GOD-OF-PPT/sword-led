# v0.4 锻锤修正

用户最新指出“锤头、锤柄方向或比例不对”。本轮只修正现有工具表现，不引入瞄准、时机或新的锻造步骤。

现版复现证据显示：选择旧素材真实金属面边，而非此前特效任意锚点，接触时边缘仍倾斜56.61°，握柄到旋转原点约104.71 CSS像素。CSS存在60°/135°/−90°多层历史覆盖，最终−90°没有把实际锤面校正为朝下，26%/80%的转轴也未跟随素材里的握柄。旧不透明点贴近特效，不能证明方向、比例或动作合理；旧回归证据保留，不改写成用户已认可。

内置imagegen按已批准D风格新绘平面钢锤：接触时金属头竖向，底部锤面平整向下，木柄水平向右，不把锤头画成加热铁坯。原PNG/prompt/引用/hash、独立锤面边和握柄像素位置见[素材记录](../design/d/hammer-forge-v2-manifest.json)。新增运行图142,696字节，格式转换保持alpha逐像素一致。旧图供旧模式继续使用，不覆盖。

v3工具只有一套尺寸/变换：按原图1536×1024保持比例，720级画面宽220px、常规宽320px；锤面中心在(200,766)，握柄支点(1380,515)。准备/下落/接触/回弹围绕握柄转动，接触时没有额外图像旋转。落下过程约55ms，接触姿态经过实际帧后再回弹；规则仍在接受点击时即时结算，姿态/音效不能追加命令。暂停、隐藏、菜单、换柄和设置改变撤销待播放动作。

为让锤面贴住不同兵器，从现有15张兵器图的实际alpha上沿读取21点轮廓，仅输出数字，不修改图片。展示落点投影到该上沿，刀弧/高阶剑不会令锤面穿入剑身；鼠标位置仍不参与随机、价格或journal。新兵器图不可用时，沿原生回退剑的上沿处理。工具在铁砧层内横向裁切，避免柄遮住委托。

验证使用独立源图锤面/握柄像素及实际Canvas不透明金属上沿，不引用运行时锚点来证明自身正确。保留旧红测、两尺寸/键鼠三姿态、三形状高低阶段、慢帧/暂停/连锻和整三轮。详细终态与边界见[本轮复核](reviews/R3-13-hammer-orientation.md)。五份core-v3源和六份SDK不改，v0.4原进度可继续；完整十二轮、最终规模及H仍保留。
