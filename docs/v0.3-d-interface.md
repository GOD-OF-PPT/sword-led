## 实际页面

`/v2.html`包含菜单、免费技法选择、两张委托择一/拒绝、三坯十点工坊、回火/淬火/交货/回收/收工确认、试剑、作品簿、日终三件收据、十二轮历史、三个商人/满槽替换/修补、胜负和重新开炉。`/`保留旧契约；两个入口共用writer锁但存档隔离。没有自动迁移、删除或覆盖旧版存档。

D场景、三锤、顾客/商人、水/油容器与三种金属纹理由内置imagegen派生，原件/提示词/引用/hash及导出见[正式美术](../design/d/README.md)。运行素材八张约2.23MiB，无外链字体/运行依赖。一个场景可在两尺寸铺陈，全部按钮、订单、配额/金币、状态和焦点由DOM渲染。图中的装饰不会成为额外经济资源。落点/锤法/来料选择后可直接空格落锤，键盘方向键与Q/W/E、1/2/3同权；十个命中区至少44×44且在两尺寸不重叠。

剑的轮廓由五节节点使用量计算；金属贴图按熟铁/精钢/陨铁分区后裁进真实轮廓，热橙随真实热度变化，淬火后冷却。纹路、完整损失与断口分别消费真实traces/integrity/status，只有一个剑尖和一个剑柄。作品簿和收据用同一画法展示保存快照，不能取回/再售；试剑也不产生新奖。

## 练习与恢复

菜单“先去练习炉”创建私有确定性局，自动完成仅必要的初始技法/拒单，再让玩家实际选点、按住/松开落锤、形成纹路、淬火、交货。每一步调用正式createRun/applyCommand；重练从新局开始。练习不读写正式存档，也不冒充正式订单已达标。关闭/取消时销毁该练习的输入句柄，旧keyup不能补交一锤。

锤击表现以当前所选落点定位，准备抬锤、接受后接触/回弹/火星；淬火后短蒸汽。换落点、换锤、换坯、局/代号/修订、设置/模态、暂停、菜单或后台都会取消不再属于当前界面的动画。已接受的经济结果不撤销。减弱动效时不运行这些短动画，仍展示准确静态结果与反馈。声音只响应接受结果；弹窗确认仍能在用户手势后播放，读取/显示不重播。

设置分别显示“正在使用默认设置”“设置已保存”“设置尚未保存”或读取问题。音频分别显示等待手势、可用、静音、浏览器阻止或无可用输出，不把静音/失败当规则失败。美术加载失败有可读提示与原生几何回退，允许继续锻造/存档。保存失败、只读、冲突、备份和不保存续玩使用原会话出口；正常保存时隐藏无关恢复按钮。

## 验证与保留责任

新增页面检查通过真实键盘/鼠标，不设置钱包、注入终局或调用生产测试控制器。完整十二轮会逐步与正式规则对照，记录三个商人/刷新、纯键盘指针计数、胜负/重开、真实赚取的修补/替换、练习隔离、动效取消和实际资源解码。结果与截图在本轮最终报告归档。

T11.4仍负责最终广浏览器/生命周期/组合故障/性能与真人再玩，T12负责最大R4和完整交付。一次固定配方能通关只证明可达，不证明路线足够丰富；真人对新意、重复、听感和操作的评价继续如实记录，不能由图稿偏好或绿测试代替。
