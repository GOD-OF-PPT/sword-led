# T08 工坊接线与输入合同

依据为已确认v0.2、B美术和S03/S05/U01/U02/U04。当前任务完成正式主页、主菜单、独立教学、工坊视图、时机输入、反馈和暂停；T09负责完整经营/结算/终局表现及R3，T10负责声音、设置持久化和进一步品质检查。

## 装配与状态

正式局只从PersistentSession读取；所有命令通过dispatch，恢复/新开走其明确确认接口。应用层只持有路线、选中件、锤法、暂停、表现反馈与独立教学局，不复制正式钱包/随机状态。规则版本forge-v1不改。

主菜单展示真实存档概要，允许新开、继续、教学和操作设置。工坊必须有真实交货/回收/结算出口，因此本轮提供连接正式内核的基础阶段路由；它不代替T09的三件复盘、完整交易/终局设计与整局验收，不把后续任务提前打勾。所有可见按钮执行真实动作或明确的导航，不放无作用的未来功能按钮。

生产应用与既有SDK分别构建到同一dist，SDK接口和存储测试仍可独立复跑。设计预览留在design目录，不作为正式入口或测试后门。

## 单次输入

唯一attempt记录runId、revision、持久化generation、应用输入epoch、目标、锤法、周期、开始事件时间与输入所有者。鼠标/空格统一；重复keydown、混合输入、非主指针和不匹配释放不能再开/完成第二击。

松开时使用松开事件timeStamp减开始事件timeStamp，通过与rAF相同的三角波计算0–10000整数落点。rAF只绘图；不用上一帧位置、不按帧数收费。低热/无煤/满阶等合法性仍由正式视图和命令验证。

事件时间使用平台记录的相对高分辨率时间，遵循浏览器精度；定义见[DOM标准](https://dom.spec.whatwg.org/#dom-event-timestamp)。测试侧Clock会覆盖performance/Event.timeStamp/rAF，须与原生输入/生命周期检查分开，见[Playwright官方说明](https://playwright.dev/docs/clock)。

切目标/锤法/慢速、button失焦、pointercancel/lostcapture、窗口blur/hidden、Esc/暂停/弹窗、新开/恢复/离开均取消准备。旧keyup/pointerup与旧动画回调不能作用于新状态。键鼠准备时拥有同一个反馈锁。

规则接受并尝试保存后才播放约450ms反馈；保存失败不撤销结果也不重击。表现锁在提交前建立；暂停取消动画，已接受结果保留。时机等级与成功/裂损分别展示，精准不被写成必成功。

## 教学与表现

教学从独立createRun创建并只调用正式applyCommand，不写玩家存档。裂痕演示由固定种子的真实命令准备，不给钱包/完整度赋值，不假称它是正式随机。随时跳过或重看，回到正式局时不推进其随机流。

正式场景读取T07实际矩形和锚点，采用DOM文字/控件与Canvas独立背景/锤砧/铁件层。材质层与静态背景缓存，空闲不持续rAF；DPR封顶2。所有游戏数字来自RunView，种子等外部文字只写textContent/value。

## 验证与回滚

单测覆盖三角波、所有者/身份/取消、独立教学和应用反馈生命周期；浏览器从生产入口以真实/可控事件验证键鼠、重复输入、取消、保存、两种桌面尺寸和素材加载。受控事件只存在测试代码，不给生产加入设置资源或强制成功接口；真实物理事件与受控边界测试分层记录。

本轮不以工坊/菜单通过宣称整局或声音/可访问性全部通过；T09–T12保留其原验收。提交保留独立T08记录，回滚用revert，不改原始input、不删除用户档或已选图。

实际交付及175单测/26页面/8存储检查、原生最小化、源/产物/截图hash见[T08验证](reviews/T08-workshop-validation.md)。共享产物的浏览器套件使用test:browser一次构建串行执行，报告输出分目录；设计美术验证只读生产图片并另存结果。
