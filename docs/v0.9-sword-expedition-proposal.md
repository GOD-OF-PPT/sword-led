# v0.9《一剑开路》：短段核心循环提案

状态：**2026-10-23已获具体批准，独立短段已实施、推送并更新本机试玩。** 批准原答、原提案commit与五文档SHA见[批准记录](approvals/v0.9-2026-10-23/approval.json)，批准合同固定于476a249；本次只更新交付状态与链接，不改变批准规则。可从[/v6.html](http://127.0.0.1:4179/v6.html)进入。[实际工具闭环](reviews/v0.9/3.1-tools-review.md)、[必要边界](reviews/v0.9/3.2-bounded-checks.md)和[最终发布回执](reviews/v0.9/3.3-delivery-review.md)区分完整新局、恢复场景和原始失败。约90秒仍是节奏目标，未宣称实测时长或趣味通过；下文算例保持原合同手算身份。

用户最新评价是当前游戏无聊、视觉不出众、缺乏可玩性。这个负评不被此前技术交付撤销。推荐只沿一个方向改核心：**打造一柄有打法的剑→亲自用它试锋开路→取得一件立即改变下一次操作的工具**。仍用左键锻造，不回十点选位、逐锤三锤型、时机／淬火／热应力多轴，也不先增加十二张订单。

## 为什么选这个方向

当前`forge-v5`的普通锤只有同一种领域意图，主要结果来自抽签；超过门槛后的收益又受同一钱袋封顶。手艺大多改变倍率／容错，未必改变玩家操作。这个判断是基于源码与当前负评的设计解释，不是已证明的全部无聊原因。

本轮五产品80条固定分桶评论及官方研究由[研究证据目录](research/evidence/2026-10-23-reboot)保留。Bladesong／Potion Craft的评论反复提出成品无后果、超规格缺用途、熟练后重复劳作、成长未改变动作；也有玩家享受创作或轻松重复。评论建议不当官方现成功能，旧版本抱怨不写成当前事实。它们支持先验证这个短循环，不能证明方案已经有趣。

## 交付范围

一个小炉台、首炉三柄新坯、两种开局技法、一台木盾卫机、吊索／铁闩二选一工具匣，以及工具第一次真实使用的固定尾声。尾声只验证取得的工具，不发第二份关卡钱、不开启完整第二章。已有v0.8完整十二天继续作为旧版保留；这次短段不得冒称完整v0.9长篇游戏。

试锋按**回合**决策，无倒计时、瞄点、连点速度或隐藏QTE。画面围绕真实剑、盾、裂纹与工具展示变化，文本／动画不决定结果；鼠标落点仍只作表现。保键盘替代、暂停／隐藏取消未完成输入、减弱动效与独立保存恢复。

## 1. 锻造：简单落锤，一次主动干预

每柄起始强度0、完好、锤数0。强度直接用于试锋伤害，不再同时铺锋利／硬度／平衡／热量表。每柄在首锤前选稳锋或裂炉，首锤后锁定流派；首炉只有**1次技法充能，跨三柄共用**。换坯不返还已用充能。

| 动作 | 规则与代价 |
| --- | --- |
| 普通左键 | 非裂损强度＋1。前三记不裂；从第四记起，完好剑裂损率20%，已裂剑再裂率35%。首次裂损这一记只使强度−1、下限0，不另加＋1；第二裂破碎。无另设普通／大成两档 |
| 锤数上限 | 普通锤或技法锤都计1记，每柄最多6记；达上限只能收锻或换坯。破碎坯退出本炉可用库存 |
| 标记技法 | 技法按钮只标记下一记，可在落锤前取消；标记不抽签、不消费。真实有效的技法锤才用掉1充能，不能延后排到另一柄 |
| 收锻 | 需至少1记且未破碎；锁定当前强度／裂纹／流派／锻纹，进入试锋后不能回炉补数值 |
| 换坯 | 放弃当前坯的本段使用，只能选尚未锻的新坯；已锻或试锋失败的剑保留回看记录，不重置／重新提交同一门 |

普通锤每次消耗一张独立1000票随机数，前三记也前进此流但裂损阈值为0；第四记起完好阈值200、已裂阈值350。主动技法的确定结果不抽签。这些参数用于独立新模式，不修改v0.8概率／journal含义。

### 两条实际不同的流派

| 技法 | 对下一记的主动效果 | 试锋特性与限制 |
| --- | --- | --- |
| **稳锋·定线** | 用1充能，下一记强度＋1且不新增裂纹；不修复已有裂纹。锻下一条连续亮刃 | 完好剑能切吊索；主要靠架剑找破绽、保住细活用途。只保证这一记，不保证后续普通锤 |
| **裂炉·崩纹** | 用1充能，尚完好的剑下一记强度＋3并必定留下崩纹裂隙；不另抽普通裂损。已裂／破碎剑禁用并说明 | 带崩纹且裂的剑伤害＋2、无视护甲；每次斩击结算后强度−2、下限0。不能切吊索。只有实际刻过崩纹的裂剑享有特性，普通意外裂纹不白送破甲 |

切剑、收锻、离炉、暂停／后台或代际变化取消尚未执行的标记；已接受的强度、裂纹、消费和随机位置保持。恢复不能补播一锤、返充能或变换流派。

## 2. 试锋：亲手用剑开路

木盾卫机耐久6、护甲2，初始盾前。每柄提交获得3个可见试锋回合；**每次有效斩击或架剑耗1回合**，不随现实时间扣减。不能换剑补满同一次试锋；失败后只能换未用新坯另开该门的一次尝试，卫机耐久重置，不继承上一柄磨掉的耐久。

| 动作 | 正式结果应如何算 |
| --- | --- |
| 直接斩击 | 无破绽时伤害max(0，强度−2)。即使伤害0也耗1回合，明确显示护甲吸收 |
| 架剑探隙 | 耗1回合、不伤耐久；下一次斩击无视护甲并伤害＋2。标记只存一份，重复架剑仍耗回合但不叠加；使用后回盾前 |
| 崩纹裂剑斩击 | 无视护甲，伤害＝当前强度＋2；若有探隙再＋2。先按当前强度算伤害，再扣强度2，不倒算伤害 |
| 通过／失败 | 每个动作只扣一次回合；动作后先判耐久≤0为通过，再判回合0为失败。失败显示三步实际效果，保剑记录，不发酬劳 |

通过立即让门／小路发生可见改变，护送者实际通行；本段一次性入账**15铜钱开路酬劳**。不是按剑强度全额卖出，不接v0.8日钱袋。相同run／门的已付标记幂等，不能靠重载／回看／重复动作领第二次。本段没有商店，15钱只是正式收据记录；核心可用回报是打开通路和工具改变操作，不拿暂未消费的货币数字当趣味依据。

## 3. 超规格剑有额外去向

通过后进入独立的取匣阶段，击破主门的那记斩击已消耗探隙，此阶段不带探隙／临时伤害加成。若仍有回合，最多选一个工具匣，或直接离开；**只接受直接工具目标尝试／离开，不再接受架剑、再斩主靶或换剑**。拒绝这些无效动作不耗回合、不改状态。有效取匣用1回合；不符合条件的点击先说明并拒绝，不扣回合、不改剑、不发物品。匣子成功后本段奖励槽关闭；不能先切绳再用剩余回合拿另一个。

| 目标 | 条件／物理结果 | 拿到什么、立即改变什么 |
| --- | --- | --- |
| 吊索工具匣 | 完好且强度≥5，耗1回合切绳、匣子落下 | **回锋齿**：尾声一次探隙斩击若有溢出伤害，存为一记可主动指定副目标的追斩；不是自动替玩家选目标 |
| 铁闩工具匣 | 铁闩护甲2；普通直击max(0，强度−2)，崩纹直击当前强度＋2且无视甲；无探隙加成。本次实际伤害≥7才耗1回合破闩，崩纹斩后仍扣强度2 | **崩炉钉**：尾声首次击破标有护甲的主目标时，恢复1技法充能、上限1，不重复触发，之后立即可在另一新坯实际用它 |

这是实际物件／动作分支，不只是成就条目或多一张作品卡。工具没有永久跨局数值；本段只带一件。基础通行不要求拿匣；低强度／三回合才过门仍可带15钱结束。

基础路线可安全做到：三普通锤＋第4记定线为完好4，或第4记崩纹为裂剑6，都足够过门，但都不够拿对应匣。安全崩纹6过门后磨到4，取匣阶段不能再用架剑把铁闩6加到8绕过门槛。额外工具至少需要一记真正有风险的普通锤：稳锋可第4普通成功（20%首裂）后第5定线到完好5，也可先定线4再普通5；裂炉推荐先第4普通成功（20%首裂）再第5崩纹到裂剑7。若先第4刻崩纹再普通第5，风险变35%二裂破碎，必须在预览中明说，不能诱导成强制劣路径。风险失败仍可放弃匣、按当前剑尝试只过主门；工具不再是安全最短路线的白送结果。

### 工具第一次使用包含在本段尾声

为避免“奖励以后才会好玩”的空承诺，取得工具者进入一次固定尾声：新炉仅在此阶段一次性补三柄新坯并给1技法充能，旧库存不转入；无新商店、无第二份15钱、无再取工具匣。新炉仍守同一6锤／流派规则。

- **回锋齿尾声**：主靶耐久2／护甲2，副靶耐久4／护甲0，3回合。用完好强度4剑先架剑，再斩主靶6；溢出4存为一次追斩，最后一回合由玩家选副靶造成4。追斩只用所存伤害、不再叠剑强度或探隙，不再耗剑强度、不递归产追斩。
- **崩炉钉尾声**：主靶耐久2／护甲2，3回合。新坯三普通锤＋一次崩纹成为强度6裂剑、技法0；斩主靶8，剑先磨损到4，工具一次回充到1。回炉选另一未锻新坯，实际用一记崩纹得强度3裂剑、充能0，完成工具用法展示。只能在该固定尾声主靶首次击破触发，不能反复刷回充。

尾声是一次有真实命令／状态的工具练习，不是伪造经济结果；不允许通过重进尾声带回新坯、金币或再次开主关匣子。锻造期可在一次性三坯内放弃／换坯，不返已消费充能；坯用尽就以练习未完成进入回顾。一旦提交尾声试锋，只进行该柄的一次3回合：回锋未清副靶、崩炉未破主靶且回合耗尽，立即进入回顾，不重置目标／回合／探隙／追斩或工具触发，不另开一次尝试。练习失败不撤已接受的主门通行／15钱／工具，也不冒称工具已经用成功。无工具者直接到回顾，不假填展示记录。

崩炉主靶成功后只有一次特殊回炉，目的仅为在另一尚未锻的新坯上实际使用刚回充的技法，不开第二次试锋、不再补三坯／重置充能或工具触发；成功用出该记后进入回顾。若没有剩余新坯则如实记录回充已发生、再次使用未展示，不造第四坯。工具尾声只重进查看回顾，不重开练习。

## 4. 手算示例与90秒操作

以下仅检验合同可理解，**不是已运行的v0.9种子／SDK／UI证据**。

- 稳锋基础：前三锤0→1→2→3，第四记定线到完好4；探隙＋斩击伤害6，2回合过主门，但强度4不能切强度5吊索，可直接带15钱结束。争匣示例是第4普通**成功**到4（该记20%裂损），再第5定线到完好5；探隙斩7过主门、余1切吊索拿回锋齿。尾声仍是完好4，探隙斩6打2耐久，溢出4追斩副靶4。
- 裂炉基础：第四记崩纹到6并裂；斩8过主门磨到4，但铁闩伤害6不足7，不能拿工具。争匣示例是先第4普通**成功**到4（该记20%裂损），再第5崩纹到7；斩9过主门磨到5、铁闩伤害7成功再磨到3，拿崩炉钉。尾声实际消费技法→破甲回充→另一坯再用一次。
- 失败：强度2普通剑直接斩盾三次伤害都是0；即使先探隙，斩击4后也不能靠最后一记盾前0补足。反馈应解释护甲2与实际伤害，玩家可改为锻到4＋探隙，或尚有充能时选裂炉主动破甲。

体验节奏目标：0–10秒看到阻路目标／两工具用途，10–30秒选择安全强度4／6只过门，或为工具先承担第4普通20%风险、成功后第5用技法做完好5／崩纹7；30–50秒用剑破机，50–65秒以额外强度完成吊索5／铁闩7，65–90秒实际用一次工具并看到回顾。风险失败是另一真实分支，不暗示必得工具。不是强迫新玩家90秒内通关，也不宣称这些时间已经测过。

## 5. 失败、调整与新开

三坯有限。试锋失败／锻碎／主动放弃的剑不重新变坯；剩余未锻坯可先选另一流派，已消耗的首炉充能不恢复。失败后显示可执行差异：改强度、用探隙、换尚可用技法或放弃额外匣，不推荐盲换seed。

首炉三坯用尽而未过门为本段失败。新开需明确动作，有进行中进度先确认可取消；新run从三坯／1充能／0钱／无工具／未付门开始，旧run的已付／工具不带入。过主门后不能返回首炉刷新尝试；先接受结果，再由尾声／回顾转移阶段。完整长篇失败继承不在此次范围，不能提前借v0.8炉谱授新战力。

## 6. UI与实现边界

沿用PC TypeScript／Vite、DOM／Canvas与纯确定性核；不因该玩法默认迁移Phaser或3D。新核拥有强度、随机、技法消费、回合、目标、工具与奖励；renderer只呈现Accepted事件。稳锋连续亮刃／切绳，裂炉贯穿裂隙／破甲的因果应可辨；有限特效不要求加全屏面板或每锤填写参数。

输入仍单次意图、busy不排队、旧回调绑定run／revision／generation／piece；暂停／隐藏只取消尚未接受的动作和表现。恢复只能重建事实，不补旧斩击／奖励。工具／失败／费用明细可展开，主画面只突出当前剑、目标和可执行选择。

已采用独立`forge-v6`／schema6、`sword-led.save.v6`／`sword-led.save.backup.v6`和`/v6.html`、`sword-led-v6.js`。完整journal重建验证状态，不把v5存档直接解释成试锋剑。v5仍按原入口／十二天／价格／schema5／炉谱解释，首段不导入旧钱包、资格、兵器、工具或数值；无新版炉谱迁移。首段先单独入口，默认首页切换不包含在本次批准，若后续要切换应另列实际发布动作和回退。

## 7. 验证、风险与停止线

批准后只做必要正式命令／回放／保存隔离／奖励一次及取消检查、严格构建，一个现代PC浏览器真实两流派与失败调整、两目标PC尺寸可见性，保明确版本身份。无需重跑v0.8的384、全音频／原生／性能、1000种子或新全矩阵。单元／页面／手算都不能替玩家觉得有趣。

主要风险：两路线可能很快变成固定答案；崩纹的确定爆发可能压过普通锤；额外匣可能强迫每局追求最优；回合试锋可能仍像算术作业。第一次体验要看玩家是否主动为不同工具改变锻造计划、能否把失败归因到可调整的决定、是否愿意试另一种打法。没出现这些反馈就回到该短循环修，不以新增章节／遗物数量掩盖。当前不把新用户反馈或技术绿色预填为趣味通过。
