# v0.8 十二灯行旅：三柄行囊

默认入口 `/` 开放三章十二天，标题与炉前显示“v0.8 十二灯行旅 · 三柄行囊”。已经保存的 v0.8 首章行程可以从第四天收据继续第五天。原 v0.7 行程仍从标题的“旧版十二灯行程”或 `/v4.html` 续玩；两版独立保存，旧金币和兵器不会搬入新局。

## 先玩一炉

1. 看来客纸单，选左侧兵器；首锤前可以换配方，首锤后定型。
2. 鼠标左键点中央剑身落锤，不用卡时机。剑旁显示作品身价和下一锤裂损率；首次裂损留下裂纹，再裂会断。六格锤势满后，下一次落锤是安全连锻。
3. 合格后拖剑给来客，或点右侧交剑。达标提示也可直接交出它所指的合格剑。纸单剑位只在真正收剑后盖章，一柄不能算两柄。
4. 安排余剑：明确出售、回收、献成器换手艺，或挂架留给明日。点“收工”先看逐柄回收额、契印后果和下一单，再确认。

暂停用 Esc 或行囊。设置里可静音、试听和减弱动效；取消输入、弹窗或动效不会撤销已接受的结果，也不会补发一次奖励。

## 身价、收入与成长

作品身价不是必付金币。交剑按钮显示真正收款，回执拆开委托酬劳与品质奖金。

| 章节 | 每日主委托酬劳 | 每日收购钱袋 |
| --- | ---: | ---: |
| 第1–4天 | 100 | 60 |
| 第5–8天 | 250 | 150 |
| 第9–12天 | 600 | 300 |

品质奖金、普通出售、主动回收、断剑和收工回收共用当天的钱袋。普通出售最多支付身价四分之一；回收按该剑原始来料底价四分之一计算，都受剩余钱袋限制。钱袋空时普通出售禁用，剑仍在；合格委托的基础酬劳仍可领取。零价回收也会交出兵器，确认前会说明。

双剑酬劳分期支付：第8天两柄各领125基础酬劳；第11天先交合格新剑领300，再改用合格旧剑完成，只再领300。先交的新剑确实已经送出，不能收回或重复计数。

明日总共三柄：不留剑领三新坯，留一柄则是一旧剑加两新坯。取下、出售或毁掉旧剑不会补第四柄。“明日打算”和封炉前纸单会说明留剑是否合用；配方、裂纹与新旧条件不一定能靠多敲补回。余温架跨天增加留剑15%身价，保留裂纹和锤势。第12天没有明日，剑架只暂存本局记录，不会把兵器带入新局。

商人在第3、6、9天到访。等级至少3、未挂架的成器才能换手艺；普通成功加1级，大成加2级，不必固定敲三次。献出去的剑不能再交差、卖钱或留剑。铜钱也可准备后续来料或补契印；备料只提高未来新坯，不给眼前的剑涨价。第4、8天收工后各选一件炉具，已选效果可在炉边与灯路回顾中查看。

炉边事件可先查看、不决定，也始终可以拒绝。捐剑只提高明天实际发出的新坯底价；借锤、修棚只照顾第一柄新坯，同行旧剑不吃这份加成。价格、代价与当前可用兵器在确认前展示。

## 十二份约定

下表是故事模式的顺序。挑战会在原章内重排部分委托，以当前纸单为准；商人仍在第3、6、9天出现。

| 天 | 真正需要交出的兵器 |
| --- | --- |
| 1 巡夜第一灯 | 无裂，身价≥100 |
| 2 重开驿路 | 无裂轻刃，普通锤≤4，身价≥160 |
| 3 修炉试锋 | 至少一次安全连锻，身价≥260 |
| 4 守住渡口 | 无裂护刃，身价≥360；关键约定 |
| 5 故剑归程 | 此前留剑≥420，或本日新剑≥630 |
| 6 逆火修行 | 带裂纹，身价≥520 |
| 7 救援重锋 | 重锋，身价≥760 |
| 8 风雪双驿 | 两柄各自无裂轻刃，各≥420；关键约定 |
| 9 炉火回响 | 同一柄至少两次安全连锻，身价≥1000 |
| 10 缺口之剑 | 带裂护刃≥1150，或无裂护刃≥1800 |
| 11 最后的接力 | 此前留剑≥1300，或两柄本日新剑各≥850 |
| 12 山口护灯 | 无裂重锋，等级≥9，身价≥2500；关键约定 |

旧剑按“来料日早于今天”判定，不限于昨天。安全连锻内的多记锤击仍只算一次连锻。双剑路线必须分别交出两柄合格兵器。

## 结局与下一程

每日未完成扣一枚契印，护炉契只免本局首次一次扣印，不补回约定。契印归零立即进入“炉火暂熄”。第12天收工后，仍有契印、实际完成至少10单且第4、8、12天都履约，才是“十二灯复明”；其余保有契印的行程是“灯下归途”。护灯剑交付后还要收工，交出护灯剑也不等于必定完美结局。

结束页按真实收件展示三人的后话、缺失约定与作品。炉谱保留各委托最佳成品，并标明旧行程或新经营来源。成功结局安全保存后可开启行脚挑战；挑战另开新局，金币、兵器和来料升级重新开始。

旧炉谱主册和备份须分别预览、明确确认导入。预览列出章节、配方、熟练、手艺见闻、挑战资格和作品；只并集这些成长，不带入旧钱包或局内兵器。来源变化或预览失焦后需重新查看；当前局资格保持，下一次启程才用已保存的新资格。

保存详情可重试本局与炉谱、导出或明确不保存续玩。同源另一个窗口只读；不保存试玩不会写新炉谱，关闭或刷新前请导出想保留的行程。
