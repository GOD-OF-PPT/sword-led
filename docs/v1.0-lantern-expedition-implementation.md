每项真实完成后记改动、必要验证、剩余和[杠精审查]并提交。失败原件、旧资产和存档保留；回滚用新revert或旧快照。若实际规则算例不成立，修合同／实现前先明确差异，不把消费者期望改绿代替设计修正。测试与低版本兼容仍是最低优先级，主要时间用于主线、互动、内容与美术。
