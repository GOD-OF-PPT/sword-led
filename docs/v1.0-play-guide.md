# 护炉远行：把剑带到母灯

母灯在山口熄了。你和阿岚、阿禾、杜伯推着小炉车，带唯一灯芯过河、上雪线、穿过落石，最后用一柄真正由你打造的剑修复母灯。每站做过的事会留到后面，终点有三个完整结局。

## 第一柄剑

点“为这趟路，打一柄剑”，在中央剑身按鼠标左键。普通前三记安全，每记加1；第四记起完好剑有20%首裂风险，首裂减1，再裂35%会碎。每柄最多六记，随时可以收锻。

这一章三枚铁坯共用一次手艺。三记普通锤后用定线能稳妥得到4强度；用崩纹能得到6强度，但留下真正崩纹，每次斩后磨损2。手艺按钮点击就用出一记，不需先选流派。换新坯不返还次数。

收锻时选手中或备用空位；替换已有剑会明确确认。想留住杜伯旧剑，可先把新剑放备用，再点备用剑换手。你不必每站重打造，两柄真实兵器可以一路带到终章。

## 路上的两步

每轮有两行动。点实体目标出剑、架剑、换剑、操作机关或战地续炉各花1步。鼠标移到目标可看这柄剑的实际伤害与磨损，读信息不推进局面。

普通伤害会扣甲；架剑本轮挡3，并让下一斩无视甲加2。崩纹自己穿甲加2，同时消耗剑强度；磨到0就真的断。架剑每轮一次，破绽不会叠加。

点“结束本轮”才结算活威胁和环境压力，先减援手、再减护势，余数扣灯火。也可以提前结束，但未用行动不会留下。0行动时，若仍有免费追斩或援手，可先用再结束。

## 谁会帮你，剑会去哪里

断桥可用完好3强度剑切索，或破闩。救摆渡人会换来双驿的实际帮助；保货则得到5钱。渡口清敌或守满三轮都能撤，额外再守一轮才会留下接应。

北驿与南驿能按顺序救援。继续赶另一处通常付1灯火，摆渡人带路则免付，他还能替双驿其中一处牵索一次。北驿与南驿后来的帮助，还取决于你有没有把恒温环留在避难炉。

避难炉可以留一柄仍持有、未断且至少3强度的剑撑梁，或亲手破锁；交出的剑离开剑架。留环让炉火保住，取环让终局每轮少2压力，但援手会转去撤离居民。缺口时交给阿岚的必须是备用剑，他本场每轮多挡2，你也真实少一柄退路。

## 随行工具与炉边的钱

回锋齿存首次斩击击破时的正溢出，能免费追斩一次；二级可以把未用余力带到后面，只保新旧较大值。崩炉钉在每场首次亲手击破带甲目标时把次数补到1，已满时不会额外多得；续炉花1次数，恢复2／二级4强度，最多到收锻原值，不能救回碎剑。

第1／4／7站炉边可添煤、买坯、升阶或换工具。界面列实际花费、补入量与余额。全程只有一次升阶资格；拆仍拥有的杜伯旧剑也可换二级工具，旧剑会消失。交换工具会失去原工具与余力，升阶资格不返还。

## 终章别把最后一柄打断

传动锁先断，才能停逆转轮。灯芯必须放进灯座，轮停后架剑会变成“架稳”，随后用当前手中合格自制剑嵌入。完好刃至少3强度，真正崩纹至少1；旧剑不能冒充你的最终作品。换剑、续炉、放灯或出剑会解除架稳，结束回合不会。

让阿禾先送灯，入场灯芯已就位并有2额外护势；自己持灯则要花1步放芯，阿禾能在轮停后免费扶稳一次。她只帮架稳，不额外加护势或破绽。

## 止步、重整和继续

每章一次重整回到第1／4／7站补给后、交易和选择前，回滚本章钱、剑、工具、援手与灯芯，保留之前章节和失败经历。重整不再次发补给，也不能多领本章奖励。正在锻造时先收锻或放弃，再从“歇一歇”重整。

实际嵌剑得到“灯路复明”；有灯火时明确撤离得到“保人归途”；失败后接受败退得到“炉火暂熄”。后日谈只回应做过的事，没救到的人不会被算成救援成功。

旅程每次行动后收好。灯路和菜单可以随时阅读，读取不会耗行动；终章另开也先确认，取消保留原进度。保存异常时可重试、导出或选择本次不保存继续，旧版行囊独立保留。声音、音量和减弱动效在“歇一歇”中调整。
