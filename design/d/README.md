## 视觉与可操作语义

靛蓝布与暗木框承载总体界面；灯炉橙是热量/锤击/价值的强调色；浅纸承担委托、手艺选择、收据和账本。UI文字使用本机中文系统字体，标题优先楷体/宋体，无外部字体请求。主要色值：深靛`#172031`，纸`#f3dfb5`，墨`#302b31`，炉金`#f4b96a`，回收青`#9dc8b3`。颜色之外保留文字、图形与数值区分，焦点为青色外框。

五节十点、柄/尖、裂损与锻纹来自真实剑快照。材质纹理在运行时裁入实际轮廓；同一素材不会代替状态或改变规则。剑只在左侧有一个尖，右侧一个剑柄；剑刃为热橙、剑脊为冷蓝。发光连线是锻纹，暗色锯齿是完整损失，破碎有实际断口。来料三卡与淬火预估、金币/信用都调用正式数据。静态标题、订单、按钮与焦点为DOM，不烘进美术。

锤头锚在所选真实落点，准备、接触、回弹和火星为短表现，只有接受的锤击才播放接触反馈；换点/锤/局/阶段/设置/模态/后台会取消旧表现，动画不提交经济命令。淬火蒸汽同理。系统或设置减弱动效时保留静态锤、已接受结果和文字。三门技法以手艺签展示真实余次/触发状态，点开看完整作用，避免小屏被长说明挤压。
