## 原件与直接引用链

`originals/` 保存八份内置生成 PNG，包括保留的暗灯首轮构图尝试 `twin-stations-dark-v1-attempt1.png`；该尝试不导出、不用于运行。`prompts/` 保存每次实际生成/编辑的完整 prompt。每张 `*-source.json` 保存生成工具模式、全局原始输出路径、项目内逐字节 PNG 副本、prompt、引用路径及各自 SHA-256。验证时全局原始输出仍可读取，八份副本与生成源的字节/hash 全部一致。

- `winter-forge-v1` 引用已选工坊 `design/d/originals/forge-backdrop-v2.png`，保留相机与工作台布局。
- `returning-blade-v1`、`cracked-work-v1`、`rescue-path-v1` 引用已选 D 主参考、既有人物 atlas 和冬季工坊；实际交付兵器、数值和来源由界面独立展示。
- `twin-stations-dark-v1-attempt1` 引用 D 主参考和首章灯路；两站过于靠边，因此保留后另做母版编辑。
- `twin-stations-dark-v1` **直接编辑 attempt1**，把两站收进画面中部并保持全暗；这是最终双驿共同母图，PNG SHA-256 为 `864bd897e897d4ca158bc9ff21d13389ebb082f5629b258d42a57f5c71a58c0d`。
- `twin-stations-one-v1` 与 `twin-stations-lit-v1` **各自直接编辑同一张最终 dark PNG**，不是从一站版编辑成两站版。前者只点亮左站既有灯、窗口及邻雪反光；后者点亮左右各站既有灯、窗口及邻雪反光。两张都没有新增人物、剑、锤、标识、文字、UI 或计数。

## 双驿实际一致性与显示要求

已分别查看八张原 PNG 与七张实际 WebP。双驿三态保持同一镜头、山体/天际线、Y 形路、古松、屋顶/门口、灯杆、岩石及雪岸地理；完成状态分别明确为全暗、仅左站亮、两站分别亮。两个完整站及其邻近灯组视觉上位于归一化约 x=0.16–0.84、y=0.32–0.62 范围，外侧均保留雪景边距。该范围为目检估计，不冒称精确像素测绘。

页面必须显示完整约 16:9 画面并使用 `contain`，不能用 `cover` 裁去一站。双站亮灯只说明本章两处连接，画面没有十二灯全胜、庆典或新结局暗示。

内置生成编辑保留了地理和构图，但并非逐像素的局部遮罩替换。`verification.json` 保留只读 PNG 像素比较：天空平均通道绝对差约 4.60/4.75（0–255），中央山体约 4.40/4.58；一站版未点亮右站区仍有约 10.13 的纹理/色调差。这里不宣称未编辑区域字节相同；母版直接引用以哈希为据，构图一致以逐图目检为据。
