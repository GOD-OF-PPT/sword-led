## 体积与画质选择

最终总计 **2,384,710 bytes / 2.274236679 MiB**。2 MiB 软目标未达，超出 **287,558 bytes**；低于 **2,621,440 bytes / 2.5 MiB** 硬预算。主控明确要求硬预算内优先玩家画质，不能为软目标反复降低画质，因此最终选择 `cwebp 1.6.0 -q 72 -m 6 -metadata none`。九张最终 q72 WebP 已逐张实际查看。

保留了编码候选日志：q72 为 2,384,710 bytes；q64 为 2,169,088 bytes；q60 为 2,066,134 bytes。q60 虽达软目标，实际查看 arrival / double-fire / gap 后，细线、山雾与细碎材质压缩更明显，未选用；q64 仅作编码候选，不冒称已完整视觉验收。候选没有改变原 PNG、画面尺寸或创作内容。当前 `export-log.json` 与 `export-log-q72.json` 对应选定参数，另外两份候选日志如实保留。

## 实际验证与复查

`visual-review.json` 将本次对九张原 PNG 与九张最终 q72 WebP 的逐图目检绑定到实际 SHA；以后资源变化不能沿用这些人工目检结论。`manifest.json` 给出全部最终文件、尺寸、完整 SHA、来源、用途和预算。

`verification.json` 记录九组源文件、副本、prompt、引用、原生 PNG 尺寸/色型/透明块及 WebP 检查。九张 WebP 均成功解码为单帧，所有 RGBA alpha 的最小/最大值均为255。每张确切原 PNG 用相同 cwebp 参数重新编码到内存，SHA 与选定公开 WebP 完全一致；核验不写公开资源。实际重编码 stderr 原始字节以 `verification/encoder-logs/*.stderr.log.gz` 留存，解压字节/hash也验证，不清理其末尾换行或行尾空格；结构化 JSON 导出日志是方便阅读的摘要，不冒称原始终端字节。
