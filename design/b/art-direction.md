# B 行会手账 · 派生美术约定

T07 / 2026-10-18。用户已明确选择[主界面B v3](../concepts/main-b-v3.png)，按已确认v0.2及forge-v1实施；本项只交付美术、状态设计和拼装约定，真实游戏交互归T08–T10。

视觉保持二维手绘、深褐墨线、暖木、奶油纸和块面金属。炉火来自左侧、右上日光；不混入A的写实材质或C的低多边形。活跃铁件是视觉焦点，装饰火焰/窗景对比压低。

## 交付与分层

内置image_gen逐资产生成。背景、三锤、砧台、三材料八阶图集、商人器具为可复用位图；商人、达标/违约与通关/失败另有画面设计稿。所有完整prompt保存在prompts，原图存originals；运行图在public/assets/b，实际尺寸/alpha/图集矩形/锚点/来源由manifest登记并经检查后冻结。

背景不带HUD、锤、砧或铁件；前景对象独立，不从带假按钮的整图截出游戏。三张材料atlas各2列×4行，按行优先对应0–7阶，Canvas以sourceRect选择，保留整张原图，不以手工重画替代生成美术。热度、裂纹、应力和反馈属于独立可控层，不能把唯一铁坯烘焙成固定高热/破损状态。

图标、数字、计时条、状态字、按钮和纸签几何由DOM/CSS/Canvas绘制；主界面五区计时比例直接来自规则视图。图稿中的文字/条形长度仅用于版式，正式值均可编辑。人物/额外资源/故事/付费功能不因美术派生加入玩法。

## 色板、字体与空间

已冻结paper #f2e3bd、ink #2b211b、wood #58402c、primary #9f3f17、ember #e76a24、teal #185e67、danger #9f2d26、warning #79460c、muted #6b5c4d。实际渲染文字/按钮对比度已计算核对并≥4.5；ember仅用于热光和装饰，不承担小字阅读。纸面容器显式使用ink前景，不继承背景场景的浅字色。

标题使用系统中文衬线栈“Noto Serif SC / Songti SC / STSong / serif”；正文用“PingFang SC / Microsoft YaHei / system-ui / sans-serif”。不下载未经许可的商业字体，不把中文正文烘焙入运行素材。正文16px、辅助≥12px；间距4/8/12/16/24/32，控件≥40px，边框约2px墨线、纸签圆角小，避免厚重金属面板。

## 状态与动效约束

- 铁件八阶形态和三材料色/纹理不同；完整度减少加裂纹，最后一格加形状警示，0为碎片和“已破碎”。热度单独加暖色光，不改阶级或规则值；低热用数字和标签同步说明。
- 升级用一/二道铜色箍带、铆钉或小标记呈现，等级文字同时可见，不另造第四锤法；砧台本体与装饰层分开。
- 击打准备/落锤/接触/复位分段；反馈约450ms是展示假设，真实动作先由内核接受并保存。精准用短放射纹，普通用小接触点，偏击用偏移划痕；裂损用折线/文字，不只变红。
- 交货为纸签/封包收拢，回收为废料落入托盘；不再由动画加资源。达标、违约、胜利、失败各有图形与词义区分。
- 暂停、后台、减弱动效时停止摆动/火星/震屏；保留数字、结果和静态选中边。声音永远不是唯一提示。

## 拼装与验收

美术预览将同时检查1280×720和1920×1080；背景与可动件按归一化锚点拼装，工具完整不被裁断。透明物体需实际alpha：外缘和空隙透明、轮廓抗锯齿，无棋盘格底或矩形投影。

保留生成PNG；cwebp只作运行格式编码，允许质量优化但不重绘/抠背景/改图，alpha保真。每张图必须逐图检查、记录原图与导出hash、实际体积；首屏预算3MiB，不能靠删掉材料/状态达标。运行素材不依赖个人生成目录。

实际交付与完整引用见[美术包](README.md)、[manifest](manifest.json)及[T07验证报告](../../docs/reviews/T07-art-validation.md)。图集采用实测行带与独立锚点，不按四等分硬裁；陨铁最终v3扩大留白，终局最终v2使用正确纸质印记。288种姿态、24帧、alpha/对比度/40px控件及两尺寸浏览器拼装已实际验证，不以本约定本身代替证据。
